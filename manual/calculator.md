# 電卓 操作マニュアル

## 画面構成

- **表示欄**（上部）：入力中の数値、または計算結果を表示します。
- **ボタン**（下部）：数字、小数点、演算子（`+` `−` `×` `÷`）、`=`、`C`（クリア）。

## 基本の計算

1. 1つ目の数値をボタンで入力します。
2. 演算子（`+` `−` `×` `÷`）を押します。
3. 2つ目の数値を入力します。
4. `=` を押すと、表示欄に計算結果が表示されます。

例：`12 + 3` を計算する場合は `1` `2` `+` `3` `=` の順に押します。表示欄に `15` と表示されます。

## 続けて計算する

`=` を押す前に続けて演算子を押すと、そこまでの結果を使って計算を続けられます。

例：`2` `+` `3` `×` `4` `=` と押すと、`(2 + 3) × 4` として `20` と表示されます。

> 掛け算・割り算を先に計算する規則は適用されず、入力した順に計算されます。

## 小数を入力する

`.` を押すと小数点を入力できます。例：`0` `.` `5`

## 入力をやり直す

`C` を押すと、入力内容と計算途中の結果がすべて消え、表示欄が `0` に戻ります。

## キーボードで操作する

| 操作 | キー |
| --- | --- |
| 数字・小数点 | `0`〜`9`、`.` |
| 足し算・引き算・掛け算・割り算 | `+` `-` `*` `/` |
| 計算する | `Enter` |
| クリア | `Esc` |
