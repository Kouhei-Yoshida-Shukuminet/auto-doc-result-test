# 電卓 機能仕様

現在有効な電卓機能の仕様を記載します。変更の経緯は [変更記録](../changes/) を参照してください。

## 概要

ブラウザで動作する簡易電卓。2つの数値に対する四則演算を行い、結果を表示欄に表示する。

## 入力

| 入力 | 画面のボタン | キーボード |
| --- | --- | --- |
| 数字 | `0`〜`9` | `0`〜`9` |
| 小数点 | `.` | `.` |
| 演算子 | `+` `−` `×` `÷` | `+` `-` `*` `/` |
| 計算実行 | `=` | `Enter` または `=` |
| クリア | `C` | `Escape` |

## 振る舞い

### 四則演算

- 加算・減算・乗算・除算に対応する。
- `=` を押すと、入力済みの「数値・演算子・数値」を計算し、結果を表示する。

### 連続計算

- 演算子を続けて入力すると、それまでの式を左から順に計算し、途中結果を表示する（例：`2 + 3 × 4 =` は `20`）。演算子の優先順位（乗除優先）は考慮しない。
- 演算子を連続して押した場合は、最後に押した演算子が有効になる。

### 小数

- 小数点を含む数値を入力できる。1つの数値に小数点は1つまで。
- 計算結果は有効数字12桁に丸めて表示する（例：`0.1 + 0.2` は `0.3`）。

### クリア

- `C` を押すと、入力中の数値・演算子・途中結果をすべて破棄し、表示を `0` に戻す。

## 制約・既知の挙動

- 0で割った場合の専用のエラー表示はない。計算結果として `Infinity`（`0 ÷ 0` の場合は `NaN`）がそのまま表示される。
